# R1 v0.1 checklist

Verification record for the R1 v0.1 operating core, built on shared standard 1.0.0. Automated items are enforced by `tools/validate.py` (checks V01 to V41) and the test suite in `tests/`; run both to reproduce every result. Human items are confirmed by the reviewer named in `release-gate.md` before any publication.

Run:

```text
python tools/validate.py
python -m unittest discover -s tests -v
```
